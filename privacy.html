1. Purpose

Happy Buzz Project의 HIB OS는 승인된 Google/YouTube 계정을 이용하여 YouTube 콘텐츠 게시와 콘텐츠 및 채널 성과 분석 기능을 제공합니다.

2. Google User Data We Access

사용자가 Google OAuth를 통해 명시적으로 권한을 부여한 경우에만 필요한 Google/YouTube 데이터에 접근합니다. 권한에는 YouTube 콘텐츠 업로드, YouTube 계정·채널 정보 읽기, 승인된 YouTube 계정 작업 및 YouTube Analytics 보고서 읽기가 포함될 수 있습니다.

3. How We Use Google User Data

Google 사용자 데이터는 승인된 YouTube 채널의 콘텐츠 게시, 채널 확인, 업로드 관리 및 YouTube Analytics 성과 분석 등 HIB OS 기능을 제공하기 위해 사용합니다.

4. Storage and Security

OAuth 인증정보와 운영에 필요한 데이터는 프로젝트 소유자가 관리하는 비공개 시스템에서 접근을 제한하여 보관합니다. 공개 웹사이트 저장소에는 OAuth 액세스 토큰, 리프레시 토큰, 클라이언트 보안 비밀 또는 기타 비밀 인증정보를 게시하지 않습니다.

5. Sharing and Sale

Google 사용자 데이터를 광고 목적으로 판매하지 않습니다. 사용자가 요청한 기능 제공 또는 법률상 요구되는 경우를 제외하고 Google 사용자 데이터를 제3자에게 공유하지 않습니다.

6. User Control

사용자는 Google 계정의 보안 및 연결 설정에서 앱의 Google 계정 접근 권한을 철회할 수 있습니다.

7. Google API Services User Data Policy

Google API를 통해 수신한 정보의 사용 및 전송은 Google API Services User Data Policy와 적용되는 Limited Use 요구사항을 준수하도록 운영됩니다.

8. Retention and Deletion

Google 사용자 데이터와 인증정보는 관련 기능 제공에 필요한 기간 동안 보관하며, 더 이상 필요하지 않거나 접근 권한이 철회된 경우 관련 인증정보와 불필요한 저장 데이터를 삭제할 수 있습니다.

9. Changes

Google 사용자 데이터 사용 방식 또는 서비스 기능이 변경되는 경우 본 방침을 업데이트합니다.

10. Contact

관련 문의는 Google OAuth 동의 화면에 표시되는 Happy Buzz Project 공식 사용자 지원 연락처를 이용해 주십시오.
